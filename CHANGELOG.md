# История изменений

## [1.1.0] — 2026-10-11

### Добавлено
- Приоритеты задач: 1 — низкий, 2 — средний (по умолчанию), 3 — высокий
- Сортировка по приоритету (при равном приоритете — по дедлайну)
- Редактирование задач: название, дедлайн, приоритет. Изменение применяется целиком или не применяется совсем
- API: `PATCH /api/tasks/{id}`, параметр `priority` в `POST /api/tasks`, `sort=priority`
- Веб: выбор приоритета, кнопка редактирования, цветная метка приоритета
- Unit-тесты на GoogleTest (55 тестов)
- CI на GitHub Actions: сборка и тесты на Ubuntu и Windows

### Изменено
- Общие функции `getToday` и `parseTags` вынесены в `Utils`
- Конец ввода в консоли обрабатывается через отдельный класс исключения `InputClosedError`
- CSV: добавлен столбец `priority`

### Исправлено
- CSV из Windows (`\r\n`) больше не добавляет `\r` к последнему полю
- Загрузка файла с повторяющимися id теперь выдаёт ошибку

### Совместимость
- Файлы `tasks.json` и CSV версии 1.0 загружаются без изменений, задачи получают средний приоритет

## [1.0.0] — 2026-09-30

- Консольный менеджер задач: добавление, удаление, поиск, теги, дедлайны
- Сохранение в JSON (собственный парсер) и CSV
- Веб-интерфейс: HTTP-сервер на cpp-httplib, HTML/CSS/JS
