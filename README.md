# Task Manager: C++17

Менеджер задач с консольным и веб-интерфейсом. Вся логика (хранение задач, поиск, валидация, сохранение в JSON/CSV) написана на C++ и используется в двух программах:

- **`task_manager`**: консольное приложение с меню
- **`task_web`**: HTTP-сервер на C++ с REST API и веб-страницей (HTML/CSS/JS)

## Возможности

- Добавление, удаление и отметка задач как выполненных
- Дедлайны с проверкой корректности даты (включая високосные годы)
- Теги и фильтрация по ним
- Поиск по названию без учёта регистра (латиница и кириллица в UTF-8)
- Сортировка по дедлайну, список просроченных задач
- Сохранение и загрузка в **JSON** (собственный парсер, без сторонних библиотек)
- Экспорт и импорт в **CSV** с корректной обработкой кавычек и запятых
- Обработка ошибок: неверный ввод, несуществующие задачи, повреждённые файлы
- Веб-интерфейс со светлой и тёмной темой и адаптивной вёрсткой

## Технологии

| Область        | Что использовано |
|----------------|------------------|
| Язык           | C++17 |
| Сборка         | CMake |
| STL            | `std::vector`, `std::string`, `std::sort`, `std::fstream`, `std::stringstream`, `std::mutex` |
| ООП            | классы, инкапсуляция, разделение ответственности |
| Ошибки         | исключения `std::invalid_argument`, `std::out_of_range`, `std::runtime_error` |
| Сеть           | [cpp-httplib](https://github.com/yhirose/cpp-httplib) (header-only, MIT) |
| Веб            | HTML, CSS, JavaScript (`fetch`, без фреймворков) |

## Архитектура

```
Браузер (HTML / CSS / JS)
        │  HTTP + JSON
        ▼
  task_web (server.cpp) ──┐
                          ├──► TaskManager ──► Task
  task_manager (main.cpp) ┘         │
                                    ▼
                          tasks.json / tasks.csv
```

- `Task`: одна задача (id, название, дедлайн, теги, статус)
- `TaskManager`: коллекция задач, поиск, сортировка, валидация, работа с файлами
- `main.cpp`: консольный интерфейс
- `server.cpp`: HTTP API; доступ к данным защищён `std::mutex`, так как сервер обрабатывает запросы в нескольких потоках

Классы `Task` и `TaskManager` собираются в отдельную библиотеку `task_core`, которую используют обе программы.
